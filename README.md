# DMDE Master Handbook

Documentation handbook for DMDE project governance, business analysis, enterprise architecture, domain architecture, development guidance, references, and appendices.

## Repository Structure

- `docs/` - Project, business, architecture, development, reference, and appendix documentation.
- `assets/` - Logos, diagrams, icons, screenshots, and reusable templates.
- `tools/` - Templates, scripts, and examples that support handbook maintenance.
