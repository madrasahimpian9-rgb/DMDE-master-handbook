# BA-01.04 Business Domains

## Domain Overview

Business domains group related responsibilities, rules, data, and workflows. Clear domain boundaries reduce duplication and help teams define ownership, integration contracts, and implementation priorities.

## Core Domains

| Domain | Primary Responsibility | Typical Outputs |
| --- | --- | --- |
| Identity and access | Users, roles, permissions, account lifecycle, access policy. | User accounts, role assignments, access decisions, audit records. |
| Organization | Institutions, units, classes, groups, and organizational hierarchy. | Organization profiles, structure maps, membership context. |
| Academic structure | Academic periods, levels, programs, subjects, schedules. | Academic calendar, subject catalog, schedule structures. |
| Student management | Student lifecycle, profiles, enrollment, status, guardians. | Student records, enrollment status, profile updates. |
| Teacher management | Teacher profiles, assignments, workload, availability. | Teacher records, teaching assignments, workload summaries. |
| Curriculum | Learning plans, competencies, curriculum structure, mapping. | Curriculum maps, competency definitions, learning pathways. |
| Assessment | Assessment plans, grading rules, score capture, progress evaluation. | Assessment records, grades, progress indicators. |
| Reporting | Dashboards, reports, exports, scorecards, analytics views. | Operational reports, leadership dashboards, compliance exports. |
| Communication | Notifications, announcements, templates, delivery channels. | Messages, delivery status, communication logs. |
| Content and portals | Website CMS, public portal, mobile/PWA access, public information. | Pages, announcements, portal views, mobile experiences. |
| Document management | Document templates, generated records, approvals, storage references. | Documents, certificates, approval trails, templates. |
| AI services | Assisted workflows, summaries, recommendations, data exploration support. | AI-generated suggestions, summaries, guided analysis outputs. |

## Boundary Guidance

- Each domain should define its owned data, consumed data, published events, and required integrations.
- Shared concepts should be documented in enterprise architecture or reference materials.
- Cross-domain workflows should name the system of record for each decision or data element.
