# EA-00.14 Enterprise Glossary

| Term | Definition |
| --- | --- |
| Architecture decision record | A document that captures an important architecture decision, context, rationale, and consequences. |
| Business capability | A stable description of what the organization needs to do to achieve outcomes. |
| Domain | A bounded area of business responsibility, rules, data ownership, and workflows. |
| Shared kernel | A small set of shared concepts, contracts, or services reused across domains. |
| Contract-first integration | An approach where API, event, or schema contracts are defined before broad implementation. |
| Observability | The ability to understand system behavior through logs, metrics, traces, health checks, and alerts. |
| Data lineage | A record of where data originates, how it moves, and how it is transformed. |
| Technical decision record | A record focused on implementation-level technology choices and tradeoffs. |
| Baseline review | A structured review that confirms architecture documentation is ready to guide delivery. |
